## ▶️ How to Run

### Using XAMPP / phpMyAdmin

1. Start **Apache** and **MySQL** from XAMPP.
2. Open **phpMyAdmin**.
3. Open the **SQL** tab.
4. Open the file `LAB_03_Database_Systems.sql`.
5. Copy/paste the complete SQL code into the SQL editor, or import the `.sql` file.
6. Execute the script.
7. The database `university_lab03` will be created.
8. Check the tables under the database.

### Using MySQL Workbench

1. Open MySQL Workbench.
2. Open `LAB_03_Database_Systems.sql`.
3. Connect to your MySQL server.
4. Execute the complete script.
